Full benchmark protocol ↗
Workload
GPT training on seeded random byte tokens, including host batch creation.
Precision
Float32 weights and optimizer state. Receipts record eager, compiled, or queued MLX execution.
Trials
3 fresh model trials. Each uses 20 warmup steps and 100 timed steps.
Timing
All device work completes inside each trial. Queued GPU runs overlap two steps and finish with a device wait. Evaluation, saving, and warmup sit outside the timed window.
Summary
Median trial throughput. Displayed ranges span the three trials. Memory is the largest measured MLX peak.

cd nanogpt-macbook
uv sync --frozen
uv run nanogpt doctor
uv run nanogpt benchmark \
  --preset all --device gpu \
  --steps 100 --warmup 20 --repeats 3 \
  --out benchmarks/results/my-mac-gpu.json
